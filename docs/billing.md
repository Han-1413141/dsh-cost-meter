# 计费规则与数据存储

[English](billing.en.md) · [返回首页](../README.zh-CN.md)

## 费用来源

插件根据宿主上报的调用用量和已配置价格计算费用，分别记录输入、缓存读取、缓存写入、输出及推理 Token。每项用量按对应单价计算；有独立搜索或网页抓取请求费时单列计入。

- **API 费用**：按量计费渠道的金额，参与默认预算与费用汇总。
- **Plan 等值费用**：订阅调用按模型价换算的等值金额，与 API 费用分开记录。
- **余额与额度**：读取账户或套餐接口；本地估算的套餐用量在对应卡片标注。

按渠道或模型选择“自动 / Plan 订阅 / API 按量”，模型设置优先。开启“含 Plan 总额”后，汇总包含 Plan 等值。子代理费用按会话归属记录，父会话按显示设置汇总；未向宿主上报用量的外部调用可通过[外部用量快照](external-usage.md)接入。

详见[统计范围与调用明细](billing-statistics.md#简体中文)、[Search / Fetch 请求费](web-request-fees.md#中文)和[Billion Context 计费](billion-context-billing.md)。

## 单价、倍率与峰谷

价格按每百万 Token 配置，保留原价格币种。基础价、峰价与谷价各项均可设置倍率，实际单价为“单价 × 倍率”；统一倍率用于同一档位的全部项目。

启用峰谷的模型按请求发起时刻选择档位。默认峰时段为 UTC 01:00–04:00、06:00–10:00，北京时间为 09:00–12:00、14:00–18:00；周末与已配置假日全天谷价。渠道可覆盖时段、日历和假日，模型设置优先。历史调用按保存的价格版本和当时规则计价。

配置见[模型价格](custom-model-prices.md)、[渠道峰谷时段](provider-peak-schedules.md)及[峰谷提醒](peak-alert.md)。预算达到阈值时提示，调用继续执行。

## 币种、同步与历史

账本以美元保存成本，同时保存调用发生时的人民币、欧元金额。历史统计使用已保存金额，更新今日汇率不重算过去费用。详见[每日汇率与历史金额](exchange-rates.md)。DeepSeek 官方人民币价与美元价分别维护；使用人民币账单时可在“费用 → 价格”选择人民币官方价格，再同步。操作见[币种与结算](billing-currency.md#中文)。

DeepSeek 同步解析官方页面，OpenRouter 从公开目录更新。解析失败时保留原价；官方表不完整且切换币种时拒绝同步，避免混用币种。自定义模型及渠道规则按[同步规则](official-price-sync-safety.md#中文)保留。

修改单价、倍率或映射影响后续调用，已有金额保留。[主动重定价](model-history-repricing.md)需要确认，并保存账本备份、原金额与价格版本；日志不完整的记录跳过。

## 存储与凭据

- 账本位于 `$DSH_HOME/storages/cost-meter/ledger.json`，使用原子写入与批量保存；历史保留和清理见[存储管理](pricing-history-storage.md)。
- 凭据存入 DSH 凭据库，账本及浏览器状态不包含明文；设置中的密钥输入框保存后不回显。[凭据来源](balance-credentials.md)
- 配置修改自动保存；余额和套餐查询按对应来源的启用状态及刷新间隔执行。
- 套餐统计根据额度读数与本地用量，估算每 1% 额度及整个额度窗口对应的 Token 数和等值金额；同账号其他工具的用量会影响比例。[估算方法](token-plan-stats.md)
