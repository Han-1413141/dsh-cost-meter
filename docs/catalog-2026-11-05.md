# 2026-11-05 模型与套餐目录更新

本次新增 2 条渠道价格记录，均为 Mistral 转售的第三方模型。完整内置目录现有 20 个厂商 / 渠道键、360 条记录、225 个不同模型 ID；355 条已核价，5 条为 `unpriced`。DeepSeek 主表独立保存。机器可读文件为 [模型价格](provider-pricing.json)和[套餐目录](subscription-catalog.json)。

## 新模型与价格

以下为每百万 token 的美元价，按 Mistral 官方模型页核对。缓存写入按默认 5 分钟 TTL；“—”表示该条目未提供独立写入价。

| 渠道 | 模型 ID | 输入 | 缓存读取 | 缓存写入 | 输出 |
|---|---|---:|---:|---:|---:|
| Mistral API | `zai-glm-5-3-flash` | 0.15 | 0.03 | — | 0.5 |
| Mistral API | `deepseek-v4-1-flash-1017` | 0.3 | 0.007 | — | 1.2 |

两个模型都由 Mistral 在自己的端点上转售，按 Mistral 公布的价格计费，因此归入 `mistral` 渠道，而不是 `z-ai` 或 `deepseek`。Mistral 的缓存读取价与直连 Z.ai / DeepSeek 不同：GLM 5.3 Flash 直连 Z.ai 为 0.026，此处为 0.03；`deepseek-v4-1-flash-1017` 的输入与输出是 DeepSeek 自身 Flash 谷时价的两倍，这是转售加价，不是录入错误。

`mistral` 是已知厂商前缀渠道，此前这两个 ID 在 `mistral` 路由上保持未定价（费用记 0），因为未知模型在已知厂商前缀处即停止，不会继续走跨厂商兜底。自定义路由名（例如 `mistral-vibe`）不属于已知厂商前缀，会走跨厂商兜底匹配，此前会命中 DeepSeek 自己的 `deepseek-v4.1-flash` 价格，按半价入账。补入本渠道条目后，两条路径都使用 Mistral 的公布价；已知厂商前缀的判定规则和兜底顺序均未改动。

Mistral 转售的日期样后缀模型 ID（如 `deepseek-v4-1-flash-1017`）仅在 Mistral 相关渠道按 Mistral 价格解析，其他渠道（如 Ollama 标签请求）继续使用原厂（DeepSeek）峰谷价。

## 迁移与升级

目录迁移只添加新 ID、更新未被修改的旧默认价。手动价格、主动取消挂载和既有账本金额保留。价格目录用于费用匹配，推理模型配置仍由 DSH 管理。

## English

This update adds 2 provider-scoped records, both for third-party models resold by Mistral on its own endpoint: `zai-glm-5-3-flash` at $0.15 input / $0.03 cached input / $0.50 output and `deepseek-v4-1-flash-1017` at $0.30 input / $0.007 cached input / $1.20 output, per million tokens. The complete built-in catalog now holds 20 vendor/route keys, 360 records and 225 distinct model IDs: 355 executable prices and 5 explicitly unpriced entries. The separate DeepSeek table is unchanged.

Both IDs belong to the `mistral` route rather than to `z-ai` or `deepseek`, because Mistral bills them at its own published rates. Mistral's cached-input prices differ from the direct vendors' prices, and the DeepSeek model costs twice DeepSeek's own off-peak Flash rate — reseller markup, not a transcription error. Previously these IDs were unpriced (cost 0) on the `mistral` route, because `mistral` is a known vendor prefix and unknown models stop there before the cross-vendor fallback runs; a custom route name such as `mistral-vibe` is not a vendor prefix, so it fell through to the fallback and matched DeepSeek's own `deepseek-v4.1-flash` row at half price. With the entries in place both paths use Mistral's published prices; the vendor-prefix rule and the fallback order are untouched.

Date-suffixed model IDs resold by Mistral (such as `deepseek-v4-1-flash-1017`) resolve at Mistral's prices only on Mistral-related routes; other channels (such as Ollama tag requests) keep the origin vendor's (DeepSeek's) peak/off-peak pricing.

Migration adds new IDs only; customized prices, deliberate unmounts and recorded charges are preserved. Public sources are linked above; the complete checked data is shipped in the two JSON catalogs.
