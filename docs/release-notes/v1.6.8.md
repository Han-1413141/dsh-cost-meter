# v1.6.8 更新

## 修复(密钥治理,安全专项)

本版本修复两个 P0 级安全问题:API Key 明文落盘与明文回传前端。修复后**所有密钥只存放在 DSH 凭据库**——账本文件不含密钥,设置接口不再回传密钥。

### API Key 明文落盘(P0)

- **现象**:`$DSH_HOME/storages/cost-meter/ledger.json` 把整个配置(含 OpenCode Go Key、9 家 Coding Plan Key、火山方舟 AK/SK)原样写盘,本机实测存有两把明文 `sk-` 密钥。
- **修复**:账本落盘前统一脱敏——密钥字段只留空占位字符串,明文只进 DSH 凭据库;配置补丁入口同步加闸门,密钥无法再经「更新设置」回流到配置里。

### 密钥明文回传前端(P0)

- **现象**:设置接口把配置原样下发给浏览器——前端的 `type="password"` 只是界面掩码,密钥值早已发出。
- **修复**:下发的密钥字段恒为空串,只附「已配置(来源 x)」状态(来自凭据库 describe 接口,该接口专为配置 UI 设计、永不返回值本身);设置页输入框改为 **write-only**——保存后不回显,写入与清除经 `setCredential` / `clearCredential` 专用通道直达凭据库。

### 升级即自动迁移存量明文

升级后首次启动(延迟 3 秒、先于历史回填)自动把账本里的存量明文密钥逐项导入凭据库并清空,已导入的项在日志中逐条列出(只打印凭据名,不打印值)。三种结局:

1. **凭据库已有值** → 不覆盖,只清空账本里的遗留明文;
2. **凭据库可写** → 导入成功后清空;
3. **凭据库不可写且未配置** → **原样保留明文**(绝不静默丢弃用户密钥),设置页提示手动导出对应环境变量后重启,下个启动周期自动重试。

迁移期间密钥解析回落旧值,功能不中断;火山 `AKID:SK` 整串会先拆成 AK/SK 两个字段再导入。

## 破坏性变更

- **设置页密码框不再回显已存密钥**:已配置的密钥显示「已配置(来源 x)」,输入框留空表示不修改;需要换 Key 时直接输入新值保存即可(覆盖凭据库旧值),清除按钮可删除。
- 存量明文密钥升级后自动迁入凭据库;若宿主凭据服务不可写,密钥保留在账本中并给出手动导出指引。

## 其他修复与改进

- **自定义余额端点收紧**:URL 强制 https;禁止跟随重定向(凭据头不跨源转发);凭据占位符发往白名单外主机时拒绝(或警告提示配置 `customBalance.allowedHosts`)。
- **权限声明补真**:`permissions.network` 从 4 个域名补全为代码实际出站的 16 个;README 中英版补「密钥不落盘 / write-only 输入框」与隐私边界(额度类端点仅在显式启用对应 Provider 时出站)。
- **测试门禁**:CI(install-smoke)新增 verify.mjs 回归与客户端产物漂移检查;`npm test` 可用;package.json 声明 `engines: node >= 20`。
- CodeQL 测试文件误报(#7 / #10)按真实规则加抑制注释;补发 v1.6.4 / v1.6.5 / v1.6.6 三份 release notes。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.6.8/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效(存量密钥自动迁移在启动时执行),浏览器端刷新页面即可。若设置页出现「未能自动迁入凭据库」提示,请按提示把对应环境变量导出后重启,下次启动会重试迁移。
