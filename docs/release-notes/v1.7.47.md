## 升级

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.47/install.ps1 | iex
```

也可运行 `dsh plugin --profile web add dsh-cost-meter@1.7.47`。升级后重启 Web 宿主并刷新页面。Desktop 使用应用自带的 `dsh` 执行 `dsh plugin --profile desktop add dsh-cost-meter@1.7.47`，然后重新打开应用。
