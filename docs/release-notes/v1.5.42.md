## v1.5.42 更新

### 修复

- **额度横条三处缺陷(issue #52,感谢 @ProximaCentauri0 的根因分析)**:① 输入框上方额度横条的迷你进度条填充永远不可见(CSS display 缺失,行内盒宽高被忽略)——现按 ok/warn/over 变色真实显示;② chip 无法点击刷新——现点击任意 chip 即刷新对应数据源(预算 → 重取状态、Go → Go 额度、Coding Plan 厂商 → 该家全部窗口一次刷新),支持键盘 Enter/Space,刷新中显示「刷新中…」,失败原因进悬停提示;③ 同一厂商多窗口占多个 chip——现按厂商融合为一条分段显示(如 `Z.ai [5h 条] [周条]`),告警级别取所有窗口最差。

### 新增

- **Kimi Code 订阅配额查询(issue #53,感谢 @Angelyeye 提供已验证端点与实测实现)**:Kimi 项现在显示订阅的真实配额——本周配额与 5 小时滚动窗口的用量百分比与重置时刻(Kimi CLI 同款接口);填 `KIMI_CODING_API_KEY`(sk-kimi-* 订阅 Key,即 coding 推理端点用的 Key)即生效;无订阅 Key 时自动回落显示原 PAYG 余额,行为与旧版一致。
- **周末全谷价一致性回归夹具(issue #54,感谢 @xyzs996 提供 CC0 一致性向量)**:15 条档位向量 + 3 条下一切换向量钉住「周末按北京时间日历全天谷价」规则,含专门暴露「UTC 与北京日历分歧段」的合成时段用例,防止未来重构悄悄改错。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.42/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
