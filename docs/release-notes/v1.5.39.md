## v1.5.39 更新

### 修复

- **隐藏官方余额/今日消耗金额改为真正的 UI 隐藏(issues #45 / #46,感谢 @JayWu199751 的两个建议)**:v1.5.38 的「隐藏金额(隐私模式)」把金额打星(`$ ***`),不是期望的效果——现改为两个独立开关(位于 设置 → 显示 → 金额):「隐藏官方账户余额」开启后侧边栏余额行/余额进度条盒、会话页与设置页的官方余额面板**整体不再渲染**;「隐藏今日消耗金额」开启后侧边栏今日费用行、预算盒明细与悬停提示中的今日金额行、概览页今日汇总卡片**整体不再渲染**。token 与调用次数统计不受影响,适合共享屏幕与截图防泄露;v1.5.38 期间写入的隐私模式配置字段在升级后自动清理。

### 新增

- **官方价格币种:人民币原生计价(issue #47)**:DeepSeek 官方同时发布中文定价页(人民币价)。新增「设置 → 数据同步 → 官方价格币种」开关(美元·英文官方页 / 人民币·中文官方页),决定「从官方文档同步价格」抓取哪个语言的官方页;页面币种按金额符号自动检测,中文页高峰时段按北京时间折算 UTC。账本恒以美元存储:人民币价表计出的成本按展示汇率折算入账,**展示人民币时汇率往返抵消,与官方人民币账单逐分一致**;第三方模型价格仍为美元。所选币种官方页同步失败时自动回退另一语言页面并提示,可稍后重试切回。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.39/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
