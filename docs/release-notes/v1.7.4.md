## 锁版门禁修正

三个 PR 的 CI 全红并非升级本身有问题,而是仓库的「精确锁版门禁」断言**硬编码了
具体版本号**(`zod 锁定 4.4.3` 等)——Dependabot 只改 package.json,不改测试
断言,必然红。本版修正:

- 断言改为锁「精确版本格式 + zod 大版本 4」(保持防浮动区间的初衷);
- 新增 `pnpm-workspace.yaml` 排除表与 package.json 锁版的**一致性断言**——升级
  漏改排除表(导致 CI 本仓安装踩 minimumReleaseAge 年龄策略)会在测试期暴露,
  而不是 CI 安装失败。
