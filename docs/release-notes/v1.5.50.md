## v1.5.50 更新

### 修复

- **对话框下方本会话费用/Token 与今日会话不一致(issue #63, 感谢 @Alan0x01)**:`v1.5.47` 引入 `seedLength` 时,`lib/index.js:326` 将 `event.length` 无条件回退为 `seedLength`,导致非 fork 会话早期的 `seq < length` 事件被误判为种子段过滤(例: 89 次调用的会话若 `length=80`,则前 80 段被过滤),表现为对话框下方“本会话 ¥0.31 · 输入 9K …”远小于设置页“今日会话”(账本 `today.sessions` 89 次/127K/8.3M/¥1.77)与 DSH 原生行的 8.4M。`v1.5.50` 改为仅显式 `seedLength` 字段生效,`length` 仅当 header 携带 `parentSession` (确认为 fork 会话)时才作为兼容回退;投影 `stateVersion` `6→7` 使旧 checkpoint 全量重放自愈,`verify.mjs` 新增非 fork/fork `length` 行为级断言。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.50/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。历史会话徽章在下次持久化重放后自动校正(无需手动清账本)。
