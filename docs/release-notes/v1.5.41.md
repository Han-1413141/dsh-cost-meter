## v1.5.41 更新

### 修复

- **启动 OOM 修复(issue #50,PR #51,感谢 @cftest120241104-lang 的完整根因分析与修复)**:会话日志存在解压后数百 MB 的大文件(长期会话每次追加批次写一个独立 zstd frame,实测一份 50MB 日志含 11.5 万帧),且账本存在标题滞后的活跃会话时,dsh web 启动后约 20 秒内 V8 堆耗尽崩溃。已按 PR 原样采用两层修复:① 大日志改为逐帧解压、逐行解析(单文件峰值内存 ~3GB → ~750MB);② 标题/时间戳补齐只定向读取缺失会话的日志(每次启动全量重扫全部 163 份 → 只扫 1 份,补齐后零扫描;日期级回填仍走全量,行为不变)。两项均幂等,历史账单数字分毫不受影响。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.41/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
