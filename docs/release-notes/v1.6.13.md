# v1.6.13 更新

## 新增:千问 Qwen Token Plan 额度显示(issue #78)

按 @mr-mihu 的需求,设置 → Coding Plan 新增「**千问 Qwen Token Plan**」卡片:
展示月度 Credits 用量百分比与「已用 / 总额 Credits」,可上侧边栏,与其它
Coding Plan 卡片同款交互。

### 为什么是「本地估算」而不是在线查询

调研(千问平台文档 + 社区实现交叉核实)确认:**千问平台没有提供 API-Key 化的
额度查询端点**——额度数据只在控制台可见,前端查询走的是浏览器会话
(cookie + 网关 sec_token),第三方插件无法安全、稳定地复用。因此与 SCNet
超算互联网同模式接入:**按官方 Credits 抵扣率,对本地账本估算当前计费周期的
用量**——无需任何凭据、不发起网络请求,数字随每次调用实时更新。

### 使用方式

1. 设置 → Coding Plan → 「千问 Qwen Token Plan」→ 勾选启用;
2. 填写**月度 Credits 额度**(个人版以订阅页为准;缺省 500,000);
3. 可选:订阅起始日(留空按自然月;千问按月重置);
4. 可选:逐模型**抵扣率覆盖**——内置了 Token Plan 个人版 10 个文本模型的
   官方抵扣率(qwen3.8-max-preview / qwen3.7-max / qwen3.7-plus /
   qwen3.6-flash / glm-5.2 / deepseek-v4-pro / deepseek-v4-flash /
   kimi-k2.7-code / kimi-k2.6 / minimax-m2.5),官方调价或使用表外模型时
   可在卡片内手动指定(输入 / 缓存读 / 输出三费率,每百万 token 抵扣的
   Credits;留空用内置值)。

### 口径说明

- 估算只统计**在 dsh 内发起的调用**(本地账本);千问 Key 在其它工具/机器上的
  消耗不在此数字内,实际消耗以控制台为准;
- 不在抵扣表内且未手动指定费率的模型不计入;
- 千问渠道调用默认按 **Plan 类**计费:金额只记目录价等值,不动真金白银口径
  (与 SCNet 等订阅渠道一致,可在 Plan/API 分类中调整)。
