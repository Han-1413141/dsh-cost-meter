## v1.9.85 更新

- 使用 DSH 官方 SQLite 会话存储时，历史导入、重新计价和单回合费用都可以读取已关闭的会话。升级后会补入旧版遗漏的 SQLite 历史，已经手动清空的历史会继续保持清空。
- 修复分支历史重复计费。父会话和分支即使在同一毫秒产生用量，也会分别记账。嵌套分支只计入自己的请求，普通会话重启后仍保留之前的费用。
- 更新 npm 宿主依赖范围，覆盖 `0.2.3-alpha.1` 和 `0.2.3-alpha.2`。安装与计费验证使用 DSH 官方 `0.2.3-alpha.2` 和 Node.js `24.22.3`。[宿主发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.3-alpha.2)

## 已导入的分支账单

升级并重启 DSH 后，插件会核对旧分支日账的调用次数、各项 Token 和逐模型金额。记录与旧版计费结果一致时，插件先在账本旁保存 `ledger.json.before-dsh-023-fork-*.json`，再扣除继承用量。日志或金额对不上的条目保留原账。
