# v1.7.2 更新

## 修复:对账警告的币种符号不一致(issue #81)

**现象**(报告者截图):余额对账触发 drift 警告时,同一句话出现两个不同币种符号:

> 本地账本今日官方渠道费用 **$3.99** 与官方余额当日变动 **¥42** 偏差较大

本地费用侧此前恒用 `$`(账本内部为美元口径),而余额变动侧按账户真实币种
(CNY)显示 `¥`——CNY 账户下同句混排,读起来像跨币种比较,实际警告里的
偏差判定早已按汇率折算到同一币种完成。

**修复**:警告文案两侧统一由同一币种判定驱动——

- **CNY 账户**:本地费用按展示汇率折算为 `¥3.99×汇率` 显示,并附 `≈$3.99`
  参考值;变动侧保持 `¥42（≈$5.83）` 原样——两侧同为 ¥ 主币种、各带 ≈$ 参考,
  对称可比;
- **USD 账户**:维持两侧均为 `$`(行为不变)。
