## v1.5.2 更新

### 修复

- **路由 provider 下本会话费用为零**:请求携带的 provider 未在价格表登记(opencode / zen 等路由入口)时,此前按未定价计 0(已挂载的 luna、DeepSeek v4 flash 均显示 0 费用);现在自动按模型名跨厂商全库查找——先查 DeepSeek 主表(保留峰谷两档),再取其余厂商中归一化最长命中;全库无此模型才不套价。
- **宿主账本入账丢失手动覆盖与匹配模式**:计费调用补传 `priceMatch` / `priceOverrides`,与客户端估算同口径。

### 新增/变更

- **模型名匹配放宽**:忽略大小写 / 空格 / 横杠 / 点号与括号附注(如 (go)),归一化等价即命中;宽泛包含匹配——请求名包含价格表模型名即算(取最长候选),如 `gpt5.6 luna(go)` → `gpt-5.6-luna`。
- **默认挂载全部目录模型**:内置目录全部模型默认挂载(计费可用);旧账本自动补齐。**挂载 ≠ 直接显示**——是否在费用设置直接显示由逐模型「在费用设置直接显示」开关控制。
- 价格卡逐模型「在费用设置直接显示」开关(仅决定展示位置,不影响挂载与计费)。

完整变更记录见 [CHANGELOG.md](../../CHANGELOG.md)。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.2/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
