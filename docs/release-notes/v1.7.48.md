# v1.7.48 — 每轮费用明细与搜索捕获

## 每轮费用（#205）

在 DSH 0.2.0 的每轮回复下方展开“本轮费用”，即可查看各模型的输入、输出、缓存读取、缓存写入和推理 Token × 单价 ≈ 金额。单价以每百万 Token 为单位，金额跟随美元或人民币显示设置；Plan 标注为等值费用，默认总额显示 API 费用。

继续展开“逐次调用明细”，按时间查看模型调用、上下文压缩和原生搜索的独立费用。每次调用列出模型路由、五类 Token、单价与金额，长上下文价格单独标注。金额最多显示八位小数；缺少价格时用问号显示对应金额，并在总额旁提示未定价用量。

估算使用已记录用量与当前配置的价表，按调用时刻选择价表内的历史价格和峰谷档位，并保留长上下文价格。缺少用量或价格会显示提示。已完成轮次优先读取实时 Session，历史会话读取日志与插件搜索明细。模型调用、压缩及该会话的原生搜索均纳入对应轮次；子代理独立会话的费用仍通过会话级汇总查看。

## 原生搜索（#203）

新增宿主搜索事件入口，处理工具持有旧 search 方法、绕过服务包装器的情况：在该搜索的异步上下文内捕获随后的一次官方 Messages 请求，读取响应用量并保存会话明细。普通请求不因此加入搜索计费；与已有包装器同时触发时不重复计算。

完整 DSH 0.2.0-rc.2 Web profile、实际 Session、DeepSeek 搜索 Provider、Undici 和打包插件已通过本地响应集成验证，包括绕过包装器后的入账和每轮明细。完整回归、前后端 RPC 契约及客户端包体限制通过。**fnOS 报告者的实际触发原因仍未确认，#203 保留等待复测。#197 继续等待原始安装日志。**
