# v1.7.11 更新

## 网关额度(CLIProxyAPI)设置 UI 修复

- **仅剩一个来源时删不掉**:「删除来源」按钮此前只在来源数大于 1 时出现,最后一个来源永远删不掉、面板一直占位。现在始终可删,删到最后面板回到「尚未配置网关来源」的空态。
- **来源卡片可折叠**:每张来源卡片默认收起为一行(标题行三角展开,收起时标题旁显示该来源的实时状态);「添加来源」新增的卡片自动展开,方便直接填写。与设置页其它折叠区(历史 / 价格表)同一交互。
- 状态行补上缺失的「抓取于 {time}」中英文案(此前该位置直接显示键名)。

## install-smoke 窗口期修复

Windows 安装冒烟此前固定安装 `install.ps1` 里钉住的发布 tag;发版链刚合入 master、tag 还没推送的那几分钟里 tag 解析不到,作业必红(v1.7.10 实测翻车一次)。现在优先安装固定 tag,tag 未推送时退回本次被测提交并在日志明示;`install.ps1` 新增 `-Rev` 参数(CI 冒烟用,默认行为不变,仍固定 tag)。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.11/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
