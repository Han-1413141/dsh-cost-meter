# v1.8.0 — Cost statistics and conversation details

## English

Open **Settings → Cost → Cost statistics**, or **Cost details** in the conversation header.

- Today, Last 7 days, Last 30 days, All retained and custom dates; provider/model filters and API/Plan cost bases.
- Spending trends, model and conversation rankings, call counts, average cost and cache hit rate. Cross-day conversations merge once, while child conversations remain separately counted.
- Conversation breakdowns for input, output, cache reads/writes and reasoning, with individual model, compaction and native-search calls. Small amounts retain at least eight decimal places. Missing prices/logs and differences from recorded ledger amounts are explicit.
- The screen loads only when opened using the DSH 0.2.0-rc.2 module loader. Older hosts without that capability show an upgrade message. Existing metering remains available.

Amounts estimate recorded usage at configured rates; Plan shows API-equivalent value. See the [statistics guide](../billing-statistics.md#english) for the precise counting rules.

Validation: full regression suite, component interaction tests and a packed DSH 0.2.0-rc.2 Web instance with 180 synthetic calls across six conversations. The chunk route and strict statistics RPCs passed. Browser tools blocked localhost, so browser visual acceptance was not completed.

## 简体中文

入口为 **设置 → 费用 → 计费统计**，或对话标题栏中的 **费用明细**。

- 支持今天、近 7 天、近 30 天、全部保留记录及自定义日期；可按提供商、模型和 API / Plan 等值筛选。
- 展示费用趋势、模型与对话排行、调用次数、平均费用和缓存命中率。跨天对话合并，子代理分别计入一次。
- 单对话可展开输入、输出、缓存读写、推理费用，以及模型、压缩和搜索的逐次明细。小额金额至少保留八位小数，缺价、日志缺失及与账本金额的差异明确提示。
- 统计页通过 DSH 0.2.0-rc.2 模块加载器按需加载。旧宿主缺少该能力时显示升级提示，原有计费功能保留。

API 费用按已记录用量和配置单价估算，Plan 显示 API 等值费用。详细口径见[统计说明](../billing-statistics.md#简体中文)。

验证：完整回归、组件交互，以及含 6 个对话、180 次合成调用的真实 DSH 0.2.0-rc.2 Web 实例。模块路由和严格统计 RPC 均通过。浏览器工具拦截本地地址，本轮未完成浏览器视觉验收。

## Update / 更新

```sh
dsh plugin --profile web add dsh-cost-meter@1.8.0
```

Restart the matching Profile after updating. Desktop users should use the application's own CLI and `desktop` Profile as described in the [installation guide](../install-troubleshooting.md#desktop-安装与更新).

更新后重启对应 Profile；桌面端请按[安装说明](../install-troubleshooting.md#desktop-安装与更新)使用应用自带 CLI 和 `desktop` Profile。
