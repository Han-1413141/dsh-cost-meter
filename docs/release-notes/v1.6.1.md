# v1.6.1 更新

## 修复(全仓安全审计)

本版本是对整个仓库的一次完整安全与质量审计的修复落地:3 项高危、约 10 项计费/链路正确性缺陷、20 余项低危与健壮性隐患全量修复。逐项定位、复现条件与验证记录见 [security-audit-v1.6.1.md](security-audit-v1.6.1.md)。

- **账本退出丢写**:`close()` 先置关闭标志再落盘,而落盘函数对已关闭状态直接返回——每次退出都丢失最后防抖窗口内的入账。现先强制落盘再关门,写失败自动重试。
- **发版脚本命令注入**:发布标题取自更新历史文档且未转义拼进 shell;改为数组参数执行并校验 tag 格式。
- **面板空指针崩溃**:Go 额度框对月度窗口未判空,单窗空值即整树崩溃;补齐守卫。
- **路由调用小时桶漏记**:网关路由(provider 缺失)的订阅调用不进小时桶但整天段聚合计入,今日段配额用量系统性偏低;两处口径统一。
- **其余**:官方余额对账告警恢复、自定义余额提取失败不再误显 $0、历史重算后 apiCost 不再倒挂、损坏会话条目剔除、计费流中断时向上游传播取消、额度查询遇非 JSON 响应继续回退链、SCNet 订阅周期末日修正等。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.6.1/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
