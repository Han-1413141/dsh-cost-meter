## v1.5.48 更新

### 修复

- **火山方舟 GET 用量探测优化(issue #60 反馈, 感谢 @sanqiPanax 实测)**:`GetAFPUsage` 无参即可返回 `5h`/`weekly`/`monthly` + `daily` 三窗,而 `GetUsageDetails` 裸调会 `400(缺 Filter.StartTime)`。原实现 `GetUsageDetails → GetPersonalPlan → GetAFPUsage` 会先 400 再成功,用户侧无感但多一次探测。`v1.5.48` 调整 `VOLCENGINE_ACTIONS` 为 `GetAFPUsage → GetUsageDetails → GetPersonalPlan`,优先命中可用端点;同时 `normalizeVolcWindowName` 新增 `daily`/`AFPDaily` 归一(映射为 `daily` 窗口)与中文“日”兼容,未知小写窗口保留原名展示而非丢弃,避免 `AFPDaily 0%` 等窗口丢失(实测 5h 10%/周 3%/月 5%/日 0% 四窗均可出数)。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.48/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
