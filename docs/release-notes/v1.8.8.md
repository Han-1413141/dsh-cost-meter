## v1.8.8

- Fixes understated official daily spend in DSH Desktop. Signed-in account calls use the `deepseek-account` provider, which was missing from the official-channel filter. Both balance reconciliation and the daily-spend bar now include these calls and their `llm-` alias, while excluding third-party channels. Existing ledger entries are used directly; no history recalculation is needed.
- Includes the merged account-wallet integration and lifecycle fixes, automatic language selection from DSH, expanded provider catalogs and improved model-name matching. See the [changelog](../../CHANGELOG.md) for details.
