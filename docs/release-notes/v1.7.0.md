# v1.7.0 更新

## 新增:自定义 Provider 余额多配置(issue #79)

「自定义 Provider 余额」现在支持**同时配置多个提供商**(最多 8 条):

- **设置页逐条编辑**:每条独立的名称(中/英)、币种、显示位置、刷新间隔、请求
  (URL/方法/请求头/体)与解析规则,可添加、删除、单独启用;
- **侧边栏逐卡显示**:按条目显示各自余额(进度条图框或余额行),点击单条刷新,
  互不影响;某条查询失败只显示该条的错误,其它条目照常;
- **独立缓存与自动刷新**:每条按自己的刷新间隔独立缓存(软/硬失败策略与原单条
  一致),快照刷新时并行更新全部可见条目。

## 无缝升级

升级前的单条配置会在首次加载时**自动迁移为第 1 条**(名称、URL、请求头、解析
规则、显示位置全部保留),无需任何操作;旧版客户端/旧快照的兼容镜像键继续下发,
回滚到旧版本也不丢配置。

## 使用方式

1. 升级后重启 `dsh web`;
2. 设置 -> 额度 -> 「自定义 Provider 余额」:原有配置在第 1 条,点「添加配置」
   新增其余提供商;
3. 每条按需选择显示位置(侧边栏/设置页/两者/关闭)与刷新间隔。
