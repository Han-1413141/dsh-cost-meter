## v1.8.10

- Conversation badges use recorded ledger amounts, matching cumulative spending. Detail entries default to the same API / combined Plan-equivalent basis as the sidebar.
- Legacy daily amounts are restored from recorded conversation rows when all token buckets and call counts prove complete coverage. No request is repriced; anonymous and previously pruned spending is preserved.
- The ledger retains every conversation beyond the former 200-session daily limit. Cross-day rankings combine a conversation into one row. With subagent costs enabled, the ranking groups every descendant under its owning conversation, matching the selected detail without counting calls twice.
- Reverified and closed #226: automatic UI language follows DSH, including delayed language-service availability and multiple clients with different languages.
