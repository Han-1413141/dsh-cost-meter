## v1.9.96 Desktop 历史会话与 OpenDesign 额度刷新

- **历史会话。** DSH Desktop 0.2.3 使用默认 JSONL 存储时，后台账本从 v4 日志读取用量，打开长对话时无需为其他历史会话构建会话对象。会话就绪后再读取可见回合的费用。
- **OpenDesign 额度。** 启动和手动刷新共享同一次查询，侧栏在首个结果返回后显示额度。连接或响应正文停滞时，查询在 15 秒后结束，可以再次刷新。感谢 @playgithub 报告 v1.9.95 在 CachyOS 上的启动延迟，并补充手动刷新时的表现。[#608](https://github.com/Han-1413141/dsh-cost-meter/issues/608)

更新后请完全退出并重新打开 DSH Desktop。使用 DSH Web 时，请重启宿主进程并刷新页面。
