## v1.8.5

- Statistics follows DSH's native theme: neutral surfaces, light borders, compact controls and collapsible explanations, including dark mode and narrow windows.
- Cost components, call types and logged steps have readable share charts. Step shares switch between cost and count, include all filtered calls across pages, and combine the remainder after the top 12 entries.
- Expand a turn to inspect its original user inputs, then expand tools for arguments, results and status. Contents load only on expansion; tool paging and explicit long-text limits bound each response. System prompts, headers and binary attachments are excluded.
- #203: scoped official-search fetch responses now supply exact usage even without Undici diagnostics, with request-level deduplication. Pre-filter counters distinguish absent diagnostics from matcher failures. The reported Node 24.15.0 / Undici 8.10.2 combination passed DSH's real proxy installation chain in both proxy and NO_PROXY modes; the fnOS-specific cause still requires on-device retesting.
