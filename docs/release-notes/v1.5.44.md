## v1.5.44 更新

### 修复

- **安全加固:Kimi 订阅端点识别改用 URL 主机名精确匹配(CodeQL 高危告警 no. 6)**:此前判断「本次请求是否 Kimi Code 订阅端点」用的是子串匹配(`url.includes('api.kimi.com')`),理论上可被形如 `api.kimi.com.attacker.tld` 的恶意相似域名误命中并套用错误的解析器。现改用 `new URL(url).hostname` 精确等值匹配(大小写归一,非法 URL 走该厂商默认解析器),对 `api.kimi.com` 订阅配额 / `api.moonshot.cn` PAYG 余额两个真实端点的行为逐位一致,仅消除该安全隐患。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.44/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
