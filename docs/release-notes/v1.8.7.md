## v1.8.7

- **Official account balance ([#201](https://github.com/Han-1413141/dsh-cost-meter/issues/201))**: DSH Desktop can read the wallet from a signed-in official account without an extra Open Platform API key. Priority is dedicated balance key → signed-in account → model credentials. Account-query failures remain visible; signing out, changing credentials or replacing the account service invalidates old balance results and reconciliation baselines.
- **Provider pricing ([#224](https://github.com/Han-1413141/dsh-cost-meter/issues/224))**: expands the verified provider catalog, including GPT-6 Sol/Luna, GPT-6.1 Sol, Gemini 3.8 Flash and Claude Fable/Opus/Sonnet releases. OpenCode Zen metered endpoints and Go subscription references use separate catalogs. Exact variants, provider aliases, cache prices, context tiers, currency and peak/off-peak rules are kept distinct. User overrides, unverified entries and recorded historical amounts are preserved. See the [pricing sources and limits](https://github.com/Han-1413141/dsh-cost-meter/blob/master/docs/provider-pricing-2026-10.md).
- **Follow DSH language ([#226](https://github.com/Han-1413141/dsh-cost-meter/issues/226))**: automatic language follows the host across settings, conversation/sidebar views and lazy-loaded statistics. Explicit Chinese/English overrides keep priority, and resolved automatic values are not written into configuration.
- **Model-name recognition**: supports NFKC/full-width names, known-provider prefixes, Gemini `models/` resource names and date snapshots with channel annotations. Frontend and backend preserve model semantics, local origins, unpriced entries and manual zero-cost selections; cross-provider guesses no longer depend on name length.

## 中文

- **官方账号余额（[#201](https://github.com/Han-1413141/dsh-cost-meter/issues/201)）**：DSH Desktop 登录官方账号后可读取充值与赠送钱包，无需额外的开放平台 API Key。优先级为余额专用 Key → 已登录账号 → 模型凭据；账号查询失败如实提示。退出、更换凭据或替换账号服务后，旧余额、在途结果与对账基准会失效。
- **多厂商价格（[#224](https://github.com/Han-1413141/dsh-cost-meter/issues/224)）**：补齐 GPT-6 Sol/Luna、GPT-6.1 Sol、Gemini 3.8 Flash 与 Claude 新型号等已核验价格；OpenCode Zen 按量与 Go 订阅参考价采用独立目录。精确变体、厂商别名、缓存价格、上下文档位、币种及峰谷规则保持隔离，保留用户覆盖、未核价条目与已记录历史金额。来源与适用限制见[价格说明](https://github.com/Han-1413141/dsh-cost-meter/blob/master/docs/provider-pricing-2026-10.md)。
- **跟随宿主语言（[#226](https://github.com/Han-1413141/dsh-cost-meter/issues/226)）**：自动模式跟随 DSH，覆盖设置、会话、侧栏及按需加载统计页；显式中英文设置优先，自动解析结果不会写回配置。
- **模型名识别**：兼容 NFKC 全角字符、已知厂商前缀、Gemini `models/` 资源名及带渠道附注的日期快照。前后端保留型号语义、本地来源、未核价条目和手动零消耗指定，不再按名称长度跨厂商猜价。
