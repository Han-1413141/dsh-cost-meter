## v1.8.9

- Balance reconciliation now compares ledger spending and wallet changes over the same interval, including after restarts and top-ups. USD wallet progress no longer applies the CNY exchange rate.
- Usage deduplication includes the effective upstream provider in live accounting, projections and log replay. Independent requests through different providers no longer suppress each other.
- Statistics refresh records written by other processes sharing the ledger, while preserving pending local calls.
- With **Include subagents in session cost** enabled, conversation totals and billing details include all subagent descendants. Each agent has a separate ledger summary; calls, turns and steps retain their owning session. Global daily and weekly totals count each call once.

## 更新

```powershell
dsh plugin --profile desktop add dsh-cost-meter@1.8.9
```

Desktop 使用应用自带的 CLI。更新后重启宿主，在费用设置中开启“本会话费用包含子代理”；Web 用户将 `desktop` 改为 `web`。保留原有开关选择，不自动更改其他用户的设置。
