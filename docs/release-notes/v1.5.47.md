## v1.5.47 更新

### 修复

- **fork 会话徽章仍显示全量费用(issue #61, 感谢 @csliuchi 提供根因、复现数据与边界判定建议)**:已升级到 `v1.5.43` 的 `session/end-seed` 单边界方案在种子段含多个 `end-seed`(父会话自身重启产生的 11309/81434/273547 被一并拷进子会话,子会话 header `seedLength:273548`/`createdAt:09:47:38` 才是真正边界)时,仅扣回首个 `end-seed` 前的影子,中间 256 条 usage(11309~273547)被当作 own 计入,徽章仍显示全量 ¥59/156M。本次改为“最大边界 + 延迟扣除”: `session` header 记录 `seedLength`/`parentSession` 并作为边界, `end-seed` 仅更新 `seedEndSeq = max` 且过滤 `time ≥ createdAt` / `seq ≥ seedLength` 的子会话自身重启标记;首个 own 事件到达时一次性扣回全量影子并标记 `seedDeducted`,后续 `end-seed` 忽略。`stateVersion` 5→6 触发重放自愈,受污染投影自动修复为正确 own 用量(~65M/¥17)。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.47/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
