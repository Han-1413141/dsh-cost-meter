## v1.9.78 更新

- 图标侧栏中 DeepSeek 余额与峰谷时段合并为同一个图标，不再各占一个按钮。峰谷条目并入余额图标后，展开时仍完整显示原有的余额与峰谷组件，账户列表、充值链接与刷新操作保持不变。
- 余额图标常驻显示金额，复用余额行原有的币种、小数位与快照口径，不再只能靠悬停查看。查询失败或非正常状态不显示误导性的零值，改为在图标上标记告警。
- 合并图标的圆环同时表达两个维度：颜色表示当前时段（峰时橙、谷时蓝、周末与节假日绿），弧长表示距下次切换的剩余时长。颜色与提示文字统一按当前时段判定，修复峰时段可能显示谷时措辞或颜色的问题。
- 今日用量、预算、模型与本地节省等全局指标仍各自独立，不并入任何供应商。已保存顺序中的旧键 `peak` 继续定位到合并后的图标，无需重新设置。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.9.78/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
