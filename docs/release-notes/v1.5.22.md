## v1.5.22 更新

### 修复

- **Go 订阅额度面板偶发 `fetch failed`([#28](https://github.com/Han-1413141/dsh-cost-meter/issues/28))**:`opencode.ai` 的 Go 用量端点部署在 Cloudflare 之后会**间歇性重置连接**(ECONNRESET,报告者观测单次失败率 30%~70%),此前插件单次请求无重试,瞬断错误直接透传到面板。新增统一网络封装:仅对**瞬时网络错误**自动重试(默认共 4 次尝试、指数退避 300/600/1200ms,每次尝试新建超时信号);`401/403`(无订阅/Key 无效)等业务状态**不重试**,中性提示语义不变。感谢 [@NyaaCaster](https://github.com/NyaaCaster) 的详尽分析与参考补丁。
- **全部对外请求统一接入同一重试封装**:官方余额、官方定价页抓取、7 家 coding plan 额度、自定义 Provider 余额——同类 Cloudflare/网关瞬断一律自愈,面板不再残留 `fetch failed`。

### 文档

- 新增峰/谷切换提醒**双语图解**([中文](../docs/peak-alert.md) / [English](../docs/peak-alert.en.md)):网页弹窗与系统通知的真实效果截图(峰/谷 × 中/英共 8 张)、设置项速查表与使用建议,README 功能表已链接。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.22/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
