## v1.5.49 更新

### 修复

- **官方价格币种为人民币时会话费用虚高(issue #62, 感谢 @Alan0x01)**:切换 `pricingCurrency` 为 `CNY` 并从中文官方页同步后,会话标题栏/输入区徽章按人民币价直接计为美元,再经展示汇率 `×7.2` 放大,导致费用偏高。`store.account` 已正确 `usdFromCost` 落库为美元,而会话投影 `lib/index.js` 与客户端回退 `lib/client.js` 的 `usageCost` 未做同口径折算。`v1.5.49` 在两处补上 `usdFromCost` 判定(`deepseek-peak` 且 `prices.currency==='CNY'` 时 `÷exchangeRate`),使徽章与账本/预算/历史保持同一汇率往返;`verify.mjs` 补充 CNY 投影断言。

## 升级

已安装用户在任意终端重跑一行即可(重跑即为更新):

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.5.49/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效,浏览器端刷新页面即可。
