## v1.9.56 更新

- 修复费用查询提前保存账本的问题，让频繁更新在原定两秒窗口内合并，减少重复后台事务。
- 待写数据缺少计时器时安排保存，跨进程变更立即合并，显式提交和退出时完成保存。
- 隔离复现的后台事务从八次合并为一次，真实临时账本的费用和 Token 核对一致。

感谢 [@XHPAN](https://github.com/XHPAN) 提供定位、复现、对照结果和修复建议。[原始报告 #470](https://github.com/Han-1413141/dsh-cost-meter/issues/470)

[详细更新说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.9.56/docs/update-notes-1.9.56.md)
