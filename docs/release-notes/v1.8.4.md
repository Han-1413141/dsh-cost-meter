## v1.8.4

- **Compact composer statistics:** Cost details follows the native turns/speed and token/cache-hit statistics in one row. Budget chips no longer take a full row or add side margins. The short button keeps its full accessible name and tooltip.
- **Desktop installation:** `install.ps1 -Profile desktop` uses the pinned npm release by default. This avoids Desktop 0.2.0-rc.2 failing to identify an unchanged Git dependency after pnpm succeeds. Explicit `-Rev` remains available. This release does not patch the Desktop host itself.

## 中文

- 「费用明细」紧跟输入框下方的轮数、速度、Token 和缓存命中率，预算与上下文用量同排，消除整行占位造成的空白。
- Desktop 安装脚本默认使用固定 npm 正式版，避免相同 Git 地址重复安装触发“无法从依赖变更中确定安装了哪一个包”。显式 `-Rev` 保留 Git 来源；宿主本身的识别逻辑未修改。

## Desktop 更新

完全退出 Desktop，使用应用自带的 dsh 命令：

```powershell
dsh plugin --profile desktop add dsh-cost-meter@1.8.4
```

随后重新打开 Desktop。在图形安装页面选择 npm 包，并填写 `dsh-cost-meter@1.8.4`。
