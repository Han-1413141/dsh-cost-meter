# v1.8.3 — 费用入口开关与窄屏布局

## 简体中文

- 修复 #213：在「设置 → 费用 → 显示设置」中，可分别隐藏标题栏费用明细入口、输入框下方入口和本轮费用。默认保留显示。隐藏本轮费用后停止对应明细请求，重新开启会读取当前轮次。
- 修复 #214：视口不超过 640px 时隐藏标题栏费用明细入口，输入框下方入口按自己的设置显示。两个按钮使用 12px 字号和紧凑间距，明细弹窗功能保留。
- #203：增加原生搜索运行时诊断，搜索事件没有匹配到请求时也会留下覆盖缺口。诊断只保存版本和计数，不含查询、响应正文、会话 ID 或凭据。fnOS 真机漏记仍待运行时证据，本版本不宣称已修复；操作见[原生搜索诊断](../native-search-billing.md)。#197 仍待报告者补充 pnpm.log。
- 合并 #215：Zod 4.5.1 → 4.6.5。

## English

- Fixes #213: separate Display switches hide header details, composer details and turn cost summaries. Existing visibility is preserved by default; hidden turn summaries stop requesting details.
- Fixes #214: the header entry hides at viewport widths of 640px or less. The composer entry keeps its own setting. Both buttons use compact 12px text and still open the details dialog.
- #203 remains open: runtime counters now distinguish service observation, Session events, matching requests, response handling and accounting. Search events without observed requests also leave a coverage gap. No query, response body, session ID or credentials are stored in these diagnostics. The fnOS failure still needs runtime evidence. #197 still needs the reporter's original pnpm.log.
- Merges #215: Zod 4.5.1 → 4.6.5.

## 更新 / Update

```sh
dsh plugin --profile web add dsh-cost-meter@1.8.3
```

更新后重启 DSH 并刷新网页。桌面端使用应用自带 CLI 和 `desktop` Profile。Restart DSH and refresh the page; desktop users should use the application's CLI with the `desktop` profile.
