# v1.7.49 — Codex 侧栏独立开关

解决 [#207](https://github.com/Han-1413141/dsh-cost-meter/issues/207)：进入“费用 → 显示”，关闭“在侧栏显示 Codex 额度”，即可隐藏侧栏卡片，同时保留会话输入区的 Codex 额度条。英文界面对应 `Show Codex quota in sidebar`。

新配置 `codexQuotaSidebar` 默认开启，旧配置继续沿用原来的显示行为。“显示 Codex 额度”仍是总开关，关闭后两处都隐藏。重新打开侧栏开关可以恢复卡片。配置校验、RPC 传输和自动保存均覆盖该字段，且关闭侧栏卡片时解除其额度订阅。

本版包含 [v1.7.48 的每轮和逐次调用费用明细](v1.7.48.md)。#203 的 fnOS 原生搜索问题仍等待报告者复测，#197 继续等待安装日志。

## 升级

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.49/install.ps1 | iex
```

也可运行 `dsh plugin --profile web add dsh-cost-meter@1.7.49`，升级后重启 Web 宿主并刷新页面。Desktop 使用应用自带的 `dsh` 执行 `dsh plugin --profile desktop add dsh-cost-meter@1.7.49`，然后重新打开应用。
