# v1.7.12 更新

## 网关（CLIProxyAPI）额度侧边栏卡片（issue #96）

- **修复**：`display` 选「侧边栏 / 两者」此前是未接线开关——宿主每个刷新周期都正常下发网关额度数据，但侧边栏渲染路径没有任何网关分支，配置好 CPA 并开启侧边栏显示后什么都看不到。
- **现在**：每个启用的网关来源按 `display` 在侧边栏出卡（快照有账号数据才显示；查询失败/进行中留在设置页展示）。卡片行复用 MiniMax 计划卡的口径（已用百分比，≥80% 预警、≥100% 超支），多账号时行标签带 Provider 前缀，仅有 credits 的账号（如 WorkBuddy）显示文本行；可点击刷新，窄栏显示百分比方块，悬停可见各窗口重置时间与抓取时间。
- **瘦身**：客户端 bundle 改为 UTF-8 原文输出（宿主本就按 utf-8 下发），中文不再转义成 `\uXXXX`，`lib/client.js` 从 261,614 降至 **248,282 字节**，距离 DSH STORE 256 KiB 单文件上限的余量回到 ~13.9 KB。

## DSH STORE 重新上架修复（issue #239）

DSH STORE 固定 Commit 自动复检对本仓库给出两条确定性整改原因，本版逐一清除：

- **源码切片**：`src/client.js` 人类可读源码 437,004 字节，超过 DSH STORE 自动审核的 256 KiB（262,144 字节）单文件上限，更新被暂缓（此前只有压缩产物 `lib/client.js` 受控）。现按区段切为 `src/client/` 三个顺序片段，`scripts/build.mjs` 按文件名排序拼接后仍生成同一份 `lib/client.js`——切片本身不改变程序文本。
- **逐版本兼容声明**：`package.json` 新增 `dsh.compatibility.dshReleases`，对官方最新三个 DSH 发行版（0.1.2-alpha.3 / 0.1.2-alpha.4 / 0.1.2-alpha.5）逐项声明 `compatible`；此前仅 `>=0.1.0-rc.5` 范围声明，不构成 DSH STORE 的可安装兼容证据，条目被暂时下架。同时补 `dsh.compatibility.dsh` 范围与 `os`（darwin/linux/win32）声明。
- **SemVer 1.7.11 → 1.7.12**：DSH STORE 仅接受插件 SemVer 高于商城版本的新固定 Commit；版本链五处对齐（package.json / install.ps1 / 双语 README）。修复推送 master 后商城每八小时自动复检，无需人工回复。

## 升级

已安装用户在任意终端重跑一行即可（重跑即为更新）：

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.12/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效，浏览器端刷新页面即可。
