# v1.7.12 更新

## DSH STORE 重新上架修复（issue #239）

DSH STORE 固定 Commit 自动复检对本仓库给出两条确定性整改原因，本版逐一清除：

- **源码切片**：`src/client.js` 人类可读源码 437,004 字节，超过 DSH STORE 自动审核的 256 KiB（262,144 字节）单文件上限，更新被暂缓（此前只有压缩产物 `lib/client.js` 受控）。现按区段切为 `src/client/` 三个顺序片段，`scripts/build.mjs` 按文件名排序拼接后仍生成同一份 `lib/client.js`——压缩产物与 v1.7.11 逐字节一致（261,614 字节，仅生成头注释更新），行为零变化。
- **逐版本兼容声明**：`package.json` 新增 `dsh.compatibility.dshReleases`，对官方最新三个 DSH 发行版（0.1.2-alpha.3 / 0.1.2-alpha.4 / 0.1.2-alpha.5）逐项声明 `compatible`；此前仅 `>=0.1.0-rc.5` 范围声明，不构成 DSH STORE 的可安装兼容证据，条目被暂时下架。同时补 `dsh.compatibility.dsh` 范围与 `os`（darwin/linux/win32）声明。
- **SemVer 1.7.11 → 1.7.12**：DSH STORE 仅接受插件 SemVer 高于商城版本的新固定 Commit；版本链五处对齐（package.json / install.ps1 / 双语 README）。修复推送 master 后商城每八小时自动复检，无需人工回复。

## 升级

已安装用户在任意终端重跑一行即可（重跑即为更新）：

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.12/install.ps1 | iex
```

升级后**重启 dsh web** 使插件服务端代码生效，浏览器端刷新页面即可。
