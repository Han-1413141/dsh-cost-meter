# v1.8.1 — Conversation cost button and turn breakdowns

## English

Open a conversation and click **Conversation cost details** below its input box. The title bar also retains the button. The entry remains available when the cost badge is disabled or the initial statistics request fails.

- Component costs appear before overview charts: input, output, cache reads, cache writes and reasoning, with tokens × rate for every call.
- New full-conversation summaries by logged turn and by model, compaction and native-search call. Turn pages and call pages are independent; a turn spanning multiple call pages retains its full amount.
- The conversation entry opens all retained history with API and Plan equivalent values. Missing turn numbers stay explicitly unassigned. Switching conversations closes the old dialog.
- Today, last seven days, all retained history and other period filters remain available. All-conversation statistics are under **Settings → Cost → Cost statistics**.

API amounts use reported usage and configured prices; Plan amounts are subscription usage equivalents. These are not per-sentence or system/tool/history invoice allocations. See the [statistics guide](../billing-statistics.md#english).

Validation: full regression suite, shipped-client button/open/close/session-switch tests, and a packed DSH 0.2.0-rc.2 Web instance with 180 synthetic calls. The real module route, strict RPCs, turn pagination and native-search profile passed. Browser visual acceptance has not been completed.

## 简体中文

打开一个会话，点击**输入框下方的「本会话费用明细」**。标题栏也保留按钮；费用徽章关闭或首次查询失败都不会把入口隐藏。

- 输入、输出、缓存读取、缓存写入和推理费用显示在趋势图之前，每次调用可展开 Token × 单价的计算明细。
- 新增按日志轮次，以及模型调用、上下文压缩、原生搜索汇总。轮次和调用分别翻页，一轮跨多个调用页时仍显示完整金额。
- 对话入口默认显示全部保留记录，区分 API 与 Plan 等值费用。没有轮次编号的调用单列，切换会话会关闭旧明细。
- 保留今天、近 7 天、全部记录等筛选；全部会话统计仍在**设置 → 费用 → 计费统计**。

API 金额按上报用量和配置价格计算，Plan 金额是订阅用量的等值费用。当前明细按调用和计费项目拆分，不把每句话或系统提示、工具、历史上下文的估算比例当作精确账单。详见[统计说明](../billing-statistics.md#简体中文)。

验证：完整回归、发布客户端的按钮打开／关闭／会话切换测试，以及含 180 次合成调用的真实 DSH 0.2.0-rc.2 Web 实例。模块路由、严格 RPC、轮次分页和原生搜索完整 Profile 均通过。浏览器视觉验收尚未完成。

## Update / 更新

```sh
dsh plugin --profile web add dsh-cost-meter@1.8.1
```

Restart the matching DSH Profile and refresh the page. Desktop users should use the application's own CLI and `desktop` Profile as described in the [installation guide](../install-troubleshooting.md#desktop-安装与更新).

更新后重启对应 DSH Profile 并刷新网页。桌面端请按[安装说明](../install-troubleshooting.md#desktop-安装与更新)使用应用自带 CLI 和 `desktop` Profile。
