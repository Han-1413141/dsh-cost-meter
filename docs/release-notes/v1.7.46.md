# v1.7.46 — 官方余额独立凭据

修复 [#201](https://github.com/Han-1413141/dsh-cost-meter/issues/201)：账号登录模式下，模型凭据被推理令牌覆盖，余额接口持续返回 401。

在「设置 → 费用 → 官方账户余额」保存独立的开放平台 API Key，再点击「刷新余额」。密钥写入宿主凭据库的 `DEEPSEEK_BALANCE_API_KEY`，不进入插件配置、账本或浏览器返回值。未配置专用 Key 时沿用模型凭据；专用 Key 无效时显示认证错误，不切换到另一个账户重试。保存或清除会取消旧请求并重新建立对账基准。

完整回归通过。验证覆盖 DSH 0.2.0-rc.2 的真实凭据优先级、独立 Key 保存/清除、缓存取消、对账、Host/Client codec 和双语设置页。使用合成凭据与 HTTP 响应，没有查询用户的在线账户。

追加反馈中的“重装后仍禁用”已有[恢复说明](../install-troubleshooting.md)：在市场重新启用，或仅调整当前 Profile 中 `cost-meter` 的禁用标记。一键安装也会提示保留禁用状态。[#197](https://github.com/Han-1413141/dsh-cost-meter/issues/197) 缺少原始 `pnpm.log`，仍保持未关闭。

## 升级

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.46/install.ps1 | iex
```

也可运行 `dsh plugin --profile web add dsh-cost-meter@1.7.46`；Desktop 请使用实际的 `desktop` Profile。升级后重启对应宿主，Web 版同时刷新页面。
