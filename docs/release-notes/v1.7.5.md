# v1.7.5 更新

## 修复:GLM-5.3 定价与目录缺失(issue #85)

### 1. GLM-5.3 已补价

此前 z-ai 目录把 glm-5.3 标记为 `unpriced`(注释:「官方/Zen 均未公布单价,
不编造价格」)。该判定已不成立——智谱官方定价页现已公布(国内 ¥8/¥28/缓存¥2)。
本版按 OpenCode Go 目录核价收录(**与 Cloudflare Workers AI 目录一致**):

| 档位 | 价格(USD / 1M tokens) |
|---|---|
| 输入(未命中) | **$1.40** |
| 缓存命中 | **$0.26** |
| 输出 | **$4.40** |

条目 notes 注明智谱国内直连价(¥8/¥28/¥2 ≈ $1.11/$3.89/$0.28,目录价略高于
直连约 20%),便于对账时理解口径。

### 2. 新增 GLM-5.3-Flash(Ox Alpha 普惠版)

2026-08-26 正式发布的原生多模态普惠版,z-ai 与 OpenCode Go 双目录收录:

| 档位 | 价格(USD / 1M tokens) |
|---|---|
| 输入(未命中) | **$0.15** |
| 缓存命中 | **$0.03** |
| 输出 | **$0.50** |

模型名大小写差异(`GLM-5.3-Flash` 等)归一化匹配同样命中;扩展价格表新增
「GLM-5 Flash / GLM Flash」家族,可挂载后编辑。

### 3. 「同步价格」范围消歧

设置页「数据与同步」区新增说明:**「从官方文档同步价格」仅更新 DeepSeek 官方
模型价(含峰谷档)**;第三方厂商的扩展目录价(z-ai / Kimi / Qwen / Volcano 等)
不随该按钮变化——它们随插件版本发布维护。如某家价格滞后,你可以:

- 在「拓展价格表」挂载对应条目后直接编辑价格;
- 或在「模型名匹配」为任意模型手动指定价格条目。
